# Dev journal (raw notes)

(`RESUME.md`, `CONTINUITY-*.md`), agendas, and the superseded/exploratory analyses in
[`analysis-archive/`](analysis-archive/). They record how the project actually evolved, including
dead ends and course corrections.

These are **not** curated documentation. For the finished story see the top-level
[`README.md`](../../README.md), the design in [`../../DESIGN.md`](../../DESIGN.md), the design/decision
notes in [`../design/`](../design/), and the key results in [`../../analysis/`](../../analysis/).
